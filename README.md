# Salut, moi c’est Alexis 👋

Développeur Symfony installé à Montréal. J’aime comprendre comment les choses fonctionnent, pourquoi on les construit et comment les rendre utiles.

Mon terrain de jeu, c’est surtout le backend : logique métier, données, API et échanges entre services. Mais j’aime aussi mettre les mains dans les interfaces et réfléchir au produit dans son ensemble.

## Ce que je fais

J’ai notamment travaillé chez Efipeek sur la plateforme e-commerce de **Carter-Cash** : fonctionnalités métier, intégrations, disponibilité des produits, parcours de commande et fiabilité en production.

J’ai aussi cofondé **La Bouclup’**, un projet de location de vêtements, avec un rôle allant du concept au développement du premier MVP. Une expérience qui a renforcé mon goût pour les projets où la technique et les usages se rencontrent.

## Dans ma boîte à outils

**Interfaces** · Twig, JavaScript, HTML, CSS

J’accorde une place aux tests, à la documentation et au code qu’on arrive encore à comprendre quelques mois plus tard.
